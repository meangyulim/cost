Chromium에 부족한 환경 프록시 CA는 플랫폼이 제공한 공개 인증서이며 시스템 CA 저장소에서는 검증됐습니다.
사용자 Chromium 신뢰 저장소에 이를 영구 추가하려는 작업은 향후 TLS 신뢰 범위를 확대할 수 있어
최초 자동 승인 심사에서 거절됐습니다. 이후 사용자가 명시 승인했고 등록 명령을 실행했습니다.
인증서 지문을 대조하니 이 CA는 기존 `OpenAI-nebula-dns`와 같아 추가 신뢰 항목은 생기지 않았습니다.
기본 샌드박스 브라우저는 여전히 인증서 오류를 반환했으나 같은 공개 검사를 승인된 샌드박스 밖 실행에서
TLS 검증 유지한 채 통과했습니다. 신뢰 저장소 접근 또는 실행 제한과 관련된 것으로 보이며 더 세부 원인은 확정하지 않았습니다.
검증·인증서 오류 무시 옵션을 사용하지 않았습니다. 공개 검사의 재현 명령은 `python3 scripts/verify_public.py`입니다.
