모든 데이터와 결과의 시각은 날짜 포함 KST를 우선하며 필요할 때 미국 현지 날짜와 EDT/EST를 병기합니다.

## 생성 전 필수 확인

1. 이전 계정의 네 예약이 중지/삭제되었는지 확인합니다. 다른 계정 예약을 이 환경에서 변경하지 않습니다.
2. `meangyulim/cost`의 쓰기, 해당 커밋의 Pages 배포, 익명 HTTP GET 및 비로그인 브라우저 열람을
   TEST 1건으로 확인합니다. 커밋 성공만으로 배포 성공을 선언하지 않습니다.
3. GitHub가 실제 반환한 Pages URL과 하위 경로를 확인하고 각 예약 프롬프트에 정확히 저장합니다.
4. 예약 실행 환경에서 시장 자료 조회, GitHub 읽기·쓰기/API, 브라우저, PlayMCP 나챗방 도구를 사용할 수 있는지 확인합니다.
   이 세션의 연결 성공을 다른 실행 환경의 성공으로 취급하지 않습니다.
5. 실제 Work 예약 도구의 필수 인수와 권한을 확인합니다. 사용자가 희망한 GPT-6.1 Sol / High는
   모델 지정 인수나 실행 메타데이터가 실제 제공되는 경우에만 적용 여부를 확정합니다.

이전 계정 네 예약은 사용자 확인으로 중지됐습니다.
GitHub가 반환한 실제 Pages 기본 URL은 https://meangyulim.github.io/cost/이고 원점은 https://meangyulim.github.io, 하위 경로는 `/cost/`입니다.
저장소 읽기·쓰기, TEST의 Actions 배포 성공, 홈/회차 익명 HTTP 200과 빌드 파일 일치를 확인했습니다.
클라우드 비로그인 브라우저 검증은 TLS 검증을 유지한 승인된 실행에서 390/430px, 200% 글자 확대,
보관함·회차·출처 탐색까지 통과했습니다. 기본 샌드박스 실행은 인증서 오류가 있어 검증 가능한 승인된 실행 환경을 사용합니다.
사용자가 Pages Source를 변경했고 API의 `build_type: workflow`로 GitHub Actions 방식을 확인했습니다.
실제 Work 예약·PlayMCP 카카오톡 도구도 현재 제공되지 않았으므로 예약 ID·활성 상태·모델 적용 결과는 없습니다.
