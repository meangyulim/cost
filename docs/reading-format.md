# 모바일 브리핑 작성 형식

2026-10-01 사용자는 긴 문단과 과도한 출처 설명이 읽기 어렵다고 지적했다. 결론과 시장 의미를 먼저 읽을 수 있게 작성한다.

- `summary`: 짧은 한 줄 결론. 수급 미확인 등 보조 설명을 제목에 길게 붙이지 않는다.
- 보고서의 선택 필드 `reading`으로 독자용 표현을 제공한다. 가격·기준 시각·원문 출처는 기존 필드에서 그대로 렌더링된다.
- `reading.headline`: 약 25자 이내 결론.
- `reading.summary_points`: 2~3개 짧은 문장. 주요 움직임, 이유, 다음 확인 기준.
- `reading.notices`: 데이터 지연·잠정치·거래구간 차이 등 판단에 필요한 주의점만 1~2개 문장. 불확실성은 생략하지 않는다.
- `reading.issues`: 기존 이슈와 같은 순서의 3개 객체. 각 객체에 `title`, `points`(핵심 1~2문장), `meaning`(시장 의미 1문장)을 쓴다. 수치의 중복 나열과 긴 자료 대조 기록을 피한다.
- `reading.interpretation_points`: 다음 판단 기준 2~3개. 미래 상승 확률을 검증 없이 만들지 않는다.
- `reading.stocks`: 티커별 `{reason, watch}`. 이유와 다음 확인을 각각 1문장으로 쓴다.
- `reading.next_checks`: 기존 항목 순서의 `{title, detail}`. 각 설명은 짧은 1문장.
- `reading.source_labels`: 출처 ID별 `매체명 · 짧은 자료명`. 하단 원문 링크 목록에만 보인다. 링크는 반드시 원래 출처 URL을 사용한다.

원래 `sources[].note`, 계산 근거, 실행 기록은 원본 데이터에 보존한다. 독자 화면에 해시·커밋·ZIP·조회 과정·긴 달력 확인 문장을 노출하지 않는다. 중요한 수치 차이·잠정 여부는 짧은 notices나 해당 이슈에 남긴다.

기존 보고서를 다듬을 때는 원본 JSON을 수정하지 않고 `data/reading/<회차 ID>.json`에 reading 객체를 저장한다. 신규 보고서는 원본 JSON의 `reading` 필드로 작성할 수 있다. 페이지는 선택 필드가 없는 기존 보고서도 문장 단위로 나누어 표시한다.

배포 완료 뒤 카카오 전송은 별도 화면·접속 검사를 기다리지 않는다. 레이아웃 변경으로 같은 회차 요약을 중복 전송하지 않는다.

사용자가 같은 날 마감 브리핑을 다시 요청하면 `kr-close-YYYY-MM-DD-HHMM`으로 별도 회차를 추가한다. `revision_at`에 실제 재작성 시각(+09:00)을 기록하고 ID의 HHMM을 맞춘다. `as_of`는 계속 정규장 마감 시각을 유지하며, `queried_at`에는 실제 자료 조회 시각을 쓴다. 제목에 재작성 시각을 표시한다. 원래 회차와 발송 기록은 보존한다.


## 아이폰 화면용 압축 레이아웃 · 2026-10-01

사용자는 화면의 세로 부피를 줄이되 자세한 정보를 유지하고 요약이 한눈에 들어오기를 요청했다.
- 첫 화면은 짧은 결론과 핵심 3줄, 지수의 이름·값·등락률을 작은 행으로 표시한다.
- 핵심 3줄은 각 1문장, 가능하면 45자 안팎으로 작성한다. 수치는 다시 길게 나열하지 않는다.
- 이슈는 제목과 시장 의미(또는 `reading.issues[].preview`)를 먼저 표시한다. preview는 가능하면 40~50자 이내로 작성한다.
  클릭하면 원래 `fact` 전체를 펼쳐볼 수 있다. 요약과 긴 사실을 모두 기본 화면에 반복하지 않는다.
- 관찰 종목은 회사/티커·가격·등락률·짧은 이유를 먼저 표시한다.
  클릭하면 거래 구간·기준 시각·변동액·상세 이유·다음 확인 조건을 펼친다.
- 가격 구간과 자료 지연·잠정치·중요한 불확실성은 펼치기 안에만 숨기지 않는다.
  `reading.notices`를 짧게 쓰되 판단에 필요한 내용을 유지한다.
- 다음 확인 일정은 기본 화면에 표시한다. 추가 판단 기준과 계산 근거는 펼치기 안에 보존한다.
- 출처와 지난 회차는 기본 접힘 상태로 제공한다. 별도의 보관함과 기존 고유 주소는 유지한다.
- 작은 글씨나 줄 잘라내기로 정보량을 줄이지 않는다. 주요 본문 16px를 유지하고 카드·여백·중복 표시를 줄인다.
- 새 레이아웃 적용은 기존 보고서의 사실·수치·발송 상태를 바꾸지 않는다. 동일 회차 카카오 알림을 다시 보내지 않는다.

## 한 장 이미지 저장·공유 · 2026-10-01

- 보고서 상단의 `이미지 저장`은 PNG 미리보기와 다운로드를 제공한다. `이미지 공유`는 파일 공유를 지원하면 기기의 공유 창을 바로 연다. 이미지 준비 중이면 미리보기에서 준비 완료 후 공유를 누른다.
- 아이폰 공유 창에서 카카오톡 또는 이미지 저장을 선택할 수 있다. 지원하지 않는 브라우저는 PNG 다운로드와 이미지 길게 누르기를 안내한다. 카카오톡 자동 발송 기능이 아니며 사용자가 대상을 선택한다.
- 이미지는 브라우저 안에서 Canvas로 생성한다. 외부 이미지 생성 서비스·CDN·API 키·전송 서버를 사용하지 않는다.
- 원본 가격·등락률·기준 시각을 그대로 사용하고, 결론·이슈 요약·종목 이유와 확인 기준·다음 일정을 한 장에 담는다. 가격 구간·불확실성·TEST 표시는 유지한다. 내용 길이에 따라 세로 길이를 늘리며 문장을 잘라내지 않는다.
- 상세 사실·계산 근거는 기존 웹 브리핑에서 제공하며 이미지 하단에 회차 고유 주소를 표시한다. 공개 출처만 이미지에 담는다.
- 전체 보고서 생성 시 자동 적용되므로 새 한국·미국 회차도 별도 이미지 작성 작업 없이 저장·공유할 수 있다. 이번 기능 변경으로 기존 회차의 카카오 알림을 다시 보내지 않는다.
