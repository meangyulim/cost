# 두 기간의 조건부 방향 전망

2026-10-02 사용자는 당일/다음 거래일과 향후 5거래일을 함께 표시하도록 선택했다.
초기 기능은 출처를 근거로 작성하는 조건부 해석이다. 학습한 금융 예측 모델, 계산된 상승 확률, 매매 신호가 아니다.
`+ 상방 우세`, `− 하방 우세`, `± 재료 상충`, `? 판단 보류`를 서로 다른 색으로 표시한다.
확인된 등락률의 색상은 전망과 별개이며 실제 가격을 바꾸지 않는다.

## 대상과 기간

- 장전 d1: 해당 거래일 정규장. 장중 d1: 작성 이후 남은 정규장. 마감 d1: 다음 실제 거래일 정규장.
- d5: 장전/장중에는 현재 거래일을 포함한 향후 5개 거래일, 마감에는 다음 거래일부터 5개 거래일.
- 날짜를 명시하려면 공식 휴장 달력으로 계산한다. 5거래일을 5일 뒤 또는 다음 월요일로 치환하지 않는다.
- 이슈·다음 확인의 전망은 `target`에 시장/업종/관련 종목을 명시한다. 시장 전체의 영향을 개별 종목 상승으로 자동 변환하지 않는다.

## 작성 판단

각 기간에 대해 사실 → 전달 경로 → 반대 요인 → 무효·재판단 조건을 작성한다.
가능한 입력: 예상 대비 실적/지표 차이, 발표 전에 이미 반영된 가격, 기업·업종 노출, 지수·업종 상대 강도, 변동성·거래량, 금리·환율 및 당시 확인한 수급.
컨센서스·종목 이력·당시 수급 등이 없으면 미확인으로 남긴다. 과거 상승률·뉴스 제목·뉴스 개수만으로 방향을 산출하지 않는다. 같은 호재가 여러 기사에 등장해도 독립 근거처럼 가중하지 않는다.
금리·고용 뉴스는 기업이익과 할인율에 서로 다른 영향을 줄 수 있다. 지표의 단순 좋음/나쁨으로 +/-를 붙이지 않는다.
재료가 상충하면 mixed, 예정 발표나 핵심 자료가 부족하면 unknown이다. 모든 종목에 억지로 +/-를 부여하지 않는다.
up/down은 해당 기간에 방향을 지지하는 근거와 반대 요인을 설명할 수 있을 때만 사용한다. 색의 진하기로 검증되지 않은 확신도를 표현하지 않는다.

## 군중 심리와 실적 발표 경로 · 2026-10-02 추가

사용자는 실적 기대가 반영된 뒤 발표 직후·다음 장 초반 하락, 이후 상승 마감한 마이크론 사례를 제시했다.
이 경로의 정확한 저점·시각과 거래 구간은 별도 시세로 확인하기 전에는 사용자 관찰로 기록한다.
가격 경로만으로 실제 매도 주체·매수 주체·의도나 공매도 청산을 확인했다고 쓰지 않는다.

기존 방향 배지는 종가 방향과 장중 위험을 충분히 구분하지 못한다. 새 전망 작성에서는 d1/d5의 `basis`에 평가할 가격 시점과 기준 가격을 명시하고, `counter`에 장 초반/장중 되돌림 위험을 따로 적는다.
상방 전망은 장 내내 상승하거나 초반 하락이 없다는 뜻이 아니다. 종가 방향과 장중 최대 하락 위험은 별개다.
5거래일 방향을 발표 다음 몇 시간의 반등만으로 확정하지 않는다. 같은 날 반등을 실적 발표 후 며칠간의 드리프트로 분류하지 않는다.

실적 이슈는 아래 네 관점으로 근거·반대 요인·재판단 조건을 작성한다.

1. **기대 대비 결과**: 발표 전에 기록된 EPS·매출 컨센서스 및 가이던스와 실제 발표를 비교한다. 과거 최고 실적과 시장 기대 초과를 구분한다. 컨센서스가 없으면 서프라이즈 크기는 미확인이다. 발표 후 수정된 예상치를 발표 전 기대처럼 사용하지 않는다.
2. **사전 기대와 선반영**: 발표 전 5/20거래일 시장·업종 대비 수익률, 거래량, 밸류에이션을 확인한다. 사전 상승은 선반영의 대용 지표이며 증명이 아니다. 업종 전체 상승·금리·지수 영향과 구분한다. FOMO·기대 쏠림·차익 실현 압력은 가능 해석으로 적고, 확인한 투자자 행동과 분리한다.
3. **발표 후 실제 반응**: 시간외·프리마켓·정규장 개장/장중/종가를 구분한다. 거래 구간별 같은 기준 종가에 대한 변화와 거래량을 비교한다. 시가 대비 종가 상승과 전일 종가 대비 종가 상승은 다른 값이다. 지수/업종·금리의 동시 변화를 확인한다. 저점 대비 반등만으로 매수 지속을 단정하지 않는다.
4. **경로 위험과 재판단**: 장 초반 매도 후 전일 종가·당일 VWAP 회복 및 동시간대 상대 거래량이 동반되면 매도 흡수 가능성을 검토한다. 반대로 회복 실패·상대 약세가 지속되면 상방 해석을 낮춘다. VWAP나 거래량 하나만으로 방향을 확정하지 않는다. 없는 분봉·호가·거래 주체 자료는 추정으로 채우지 않는다.

정량 확장 시 검토할 수 있는 지표:

- 사전 기대 반영 대용: 발표 전 종목 수익률에서 시장/업종 영향을 조정한 초과수익률. 단순 차감은 업종 대비 비교이며 베타 조정 초과수익률과 다르다.
- 실적 서프라이즈: 실제−발표 전 예상. SUE는 과거 예측 오차 분산 등 정해진 분모·충분한 표본으로 표준화해야 한다. 성장률을 SUE로 대신 쓰지 않는다.
- 발표 반응: 전일 종가 대비 개장 갭·장중 저점·종가 수익률, 시가 대비 종가 수익률, 종가 위치, 시간외/정규장 별도 반응.
- 수급/심리 대용: 동시간대 상대 거래량·VWAP 위치, 당시의 소셜 감성·관심 급증, 옵션 내재변동성과 스큐. 옵션·소셜 자료는 현재 파이프라인에서 수집하지 않으므로 미확인이다. 콜 거래 증가만으로 강세 포지션을 단정하지 않는다.
- 옵션의 예상 변동폭과 방향 전망은 별개다. 실적 발표 후 내재변동성 하락을 주식 하락의 직접 원인으로 단정하지 않는다. 헤지 영향은 포지션·행사가·만기 등의 자료가 있어야 검토할 수 있다.

현재 수집·분석은 주로 일별 종가·거래량·상대 강도이며 분봉 경로·옵션·소셜 감성·투자자 주문 흐름 모델은 없다.
현재 배지는 이 내용을 참고한 정성적 조건부 해석이다. 위 지표를 계산했다거나 군중 심리를 정량 모델로 반영했다고 주장하지 않는다.
자료가 부족하면 종가 방향은 mixed/unknown으로 보수적으로 작성한다. 정확한 장중 저점이나 반등 시각을 예측하지 않는다.

참고 연구: [투자자 감성과 실적 발표 반응](https://arxiv.org/abs/2006.13934), [실적 발표의 고빈도 가격 반응과 시간외 미시구조](https://arxiv.org/abs/2601.08962), [실적 발표와 옵션 가격](https://arxiv.org/abs/1412.8414).

## 데이터 형식

`reading.outlook`에는 아래 메타데이터를 저장한다.

```json
{
  "method": "conditional",
  "validation": "not_validated",
  "estimated_at": "실제 작성 시각(+09:00)",
  "input_cutoff": "입력 자료의 정보 마감 시각(+09:00)",
  "added_later": false,
  "evaluation_eligible": false,
  "note": "조건부 해석이며 검증 전입니다."
}
```

각 `reading.issues[]`, `reading.stocks[티커]`, `reading.next_checks[]`에 `outlook` 객체를 추가한다.
d1/d5는 각각 아래 필드를 갖는다. 근거는 보고서의 기존 원문 `sources` ID를 참조한다.

```json
{
  "d1": {
    "direction": "unknown",
    "target": "관련 종목 또는 업종",
    "basis": "당시 확인한 자료와 판단 근거",
    "counter": "반대 요인과 자료 부족",
    "invalidation": "판단을 바꿀 관찰 가능한 조건",
    "sources": ["보고서의 출처 ID"]
  },
  "d5": {
    "direction": "unknown",
    "target": "관련 종목 또는 업종",
    "basis": "5거래일 기준 근거",
    "counter": "5거래일 기준 반대 요인",
    "invalidation": "판단을 바꿀 조건",
    "sources": ["보고서의 출처 ID"]
  }
}
```

웹에서는 배지를 기본 표시하고 두 기간의 근거·반대 요인·조건을 펼쳐 보여준다.
이미지에는 두 배지와 검증 전 상태·작성/추가 시각·자료 시각을 간결하게 포함한다. 상세 근거와 출처는 웹에 유지한다.

## 시점과 이후 검증

- 조회 시각 이후 작성한 전망은 `added_later: true`로 명시하고 실제 추가 시각을 별도로 표시한다.
- 기존 장전 회차에 개장 후 추가한 전망은 원래 장전 예측이 아니므로 `evaluation_eligible: false`로 둔다.
- 입력 마감은 작성 시각 및 보고서의 조회 시각을 넘을 수 없다. 작성 후 뉴스·가격을 이전 시점 전망의 근거로 사용하지 않는다.
- 기존 원본 보고서는 수정하지 않고 reading 오버레이에 추가한다. 전망을 사후 변경할 때는 새 시각의 회차로 남겨야 하며, 이전 전망을 덮어쓰고 적중했다고 평가하지 않는다.
- 검증하려면 먼저 실제 공개 시각 이전에 고정한 전망·당시 입력·거래 구간·기준 가격과 목표 기간을 보존해야 한다. 평가 시 가격 보정·휴장일·반복 종목·중첩된 5일 구간을 처리한다.
- 순차적인 기간 외 검증으로 항상 상승 기준과 비교한다. 상방/하방별 적중률·판단 보류 비율·표본 수를 함께 보고, 확률 모델을 추가하면 확률 보정도 평가한다. 매매 전략 성과를 주장할 때는 비용과 체결 가능 가격이 필요하다.
- 현재 모듈에는 성과 계산·백테스트·모델 학습이 없다. 평가 완료나 예측 정확도를 주장하지 않는다.

참고 연구: [Bernanke & Kuttner, 2004](https://www.federalreserve.gov/econres/feds/what-explains-the-stock-market39s-reaction-to-federal-reserve-policy.htm), [Boyd, Hu & Jagannathan](https://www.nber.org/papers/w8092).
