# 미국장 마감 후 · 실행 프롬프트 초안 (미활성)

예약: 월~금 16:15, timezone=America/New_York. 미국 시간대는 DST를 자동 반영하도록 저장하고 KST 고정 시각으로 바꾸지 않는다.
회차 ID: us-close-YYYY-MM-DD, 날짜는 뉴욕 시장 날짜.
작성 초점: 해당 뉴욕 거래일 정규장 지수·실제 영향 사건·종목 움직임.

이 작업은 meangyulim/cost 저장소와 GitHub Pages를 사용하는 주식 브리핑 클라우드 실행이다. 추가 서버, 유료 시세 API, OpenAI API 호출, 로컬 PC 예약, GitHub cron을 사용하지 않는다. 현재 채팅, 첨부, 임시 절대 경로에 의존하지 않는다. 기존 격리된 클라우드 체크아웃을 사용하며 별도 worktree를 만들지 않는다.

현재 확인 상태: 이전 계정 네 예약은 사용자 확인으로 중지됐다. 저장소는 공개 meangyulim/cost이며 Git 읽기·쓰기, TEST 커밋의 Actions 배포 성공, 익명 HTTP 200과 콘텐츠 일치를 확인했다. GitHub Pages API가 반환한 실제 기본 URL은 https://meangyulim.github.io/cost/이고 원점은 https://meangyulim.github.io, 하위 경로는 /cost/이다. 클라우드 비로그인 브라우저 검증은 TLS 검증을 유지한 승인된 실행에서 390/430px, 200% 글자 확대, 보관함·회차·출처 탐색까지 통과했다. Pages API가 build_type=workflow를 반환해 GitHub Actions 방식도 확인했다. 기본 샌드박스 실행은 인증서 오류가 있으므로 검증이 가능한 승인된 브라우저 실행 환경을 사용하며 TLS 검증을 끄지 않는다. 실제 Work 예약 도구와 PlayMCP 카카오톡 도구는 현 세션에 없다. 남은 필수 조건 확인 전에는 이 초안을 활성화하지 않는다. 모델은 사용자가 GPT-6.1 Sol / High를 희망하지만 실제 예약 도구의 모델 지정 인수/메타데이터가 있을 때만 확정한다.

매 실행:
1. 시계로 실제 시작 시각을 KST/UTC로 기록한다. 지원되는 GitHub 인증으로 https://github.com/meangyulim/cost.git의 최신 소스, data/reports, public/manifest.json, 해당 회차, dispatch 상태를 읽는다. 저장소 URL은 실제 Git 읽기로 확인되었으나 API/쓰기/배포 권한은 별도 확인한다. 토큰 값을 출력하거나 파일·Git·명령 인수에 넣지 않는다.
2. 한국장은 KRX 공식 달력, 미국장은 NYSE/Nasdaq 공식 달력을 원문으로 확인한다. 실제 시장 날짜/거래일/휴장/조기 폐장과 근거를 기록한다. 휴장일은 게시와 발송 모두 생략한다. 조기 폐장일에도 지정된 고정 시각을 유지하고 결과에 표시한다. 한국 회차 ID의 날짜는 한국 시장 날짜, 미국은 뉴욕 시장 날짜다.
3. 공개된 공식 거래소·공시·기업 IR·검증 가능한 시세 및 뉴스 원문을 조사한다. 실제로 제공된 데이터 조회 도구나 허용 HTTPS 요청을 사용하며 접근 권한을 우회하지 않는다. 필요한 데이터·도구가 없으면 실패 범위를 보고한다. 기준 시각과 조회 시각을 분리하고 날짜 포함 KST를 우선한다. 미국 현지 시각이 필요하면 날짜와 EDT/EST를 확인한다.
4. 지수는 실제 값·전일 대비 포인트·등락률. 종목은 회사/티커·실제 가격·통화·변동액/등락률·시각/거래구간. 장후는 해당 거래일 정규장 종가, 장전은 전일 정규장 종가가 기본이다. 장전/프리마켓/시간외 값은 확인된 경우 별도 구간과 시각을 표시한다. 한국 가격의 KRX/NXT 시장을 구분하고 다른 구간을 섞지 않는다. 환율·금리·수급 등 판단에 쓰는 값은 단위·기간·시장·시각을 적는다. 원문 정밀도를 유지하고 계산 근거를 남긴다. 확인 못한 값은 이유와 미확인으로 표시하며 실제 가격을 역산하거나 시안 값을 재사용하지 않는다.
5. 짧은 시장 결론, 핵심 이슈 약 3개, 매회 사건/공시와 확인한 시장 반응으로 새로 선정한 관찰 종목 약 3개, 다음 일정/확인 순서 2~3개, 클릭 가능한 원문을 작성한다. 사실과 해석을 구분한다. 확인된 발표 시각만 날짜 포함 KST로 쓰며 미확인 시간은 확인 순서로 표현한다. 중요한 불확실성을 접힌 영역에 숨기지 않는다. 기존 남색 모바일 디자인을 유지하며 본문 16px 이상, 일반 보조 14px 이상, 메타데이터 12~13px, 390~430px 및 200% 글자 확대를 점검한다.
6. 원격에 동일 회차가 있으면 새 글 생성/덮어쓰기를 하지 않고 검증/발송 상태를 확인한다. 새 원본은 저장소의 scripts/add_report.py를 사용해 data/reports/<회차 ID>.json에 추가한다. calendar_evidence와 원문 sources를 포함하고 scripts/build_site.py와 테스트를 실행한다. public/reports/<회차 ID>/index.html, 홈/보관함/manifest를 함께 생성하며 모든 이전 글을 보존한다. TEST는 실제 보고서로 바꾸지 않는다. 일반 Git 충돌 검사로 새 항목만 커밋/푸시하고 force push하지 않는다.
7. 실제 Pages 설정/API 또는 배포 메타데이터에서 반환된 URL만 사용한다. 확정된 기본 URL은 https://meangyulim.github.io/cost/이다. 회차 URL은 https://meangyulim.github.io/cost/reports/<회차 ID>/이다. API가 반환하는 주소가 변경됐으면 현재 값을 다시 확인해 사용한다. 도메인 루트 /reports를 가정하지 말고 실제 프로젝트 하위 경로에 상대 보고서 경로를 결합한다. 작성 커밋의 GitHub Actions Pages 배포 성공을 조회한다. 커밋 성공만으로 게시 성공을 주장하지 않는다.
8. 정확한 회차 공개 URL을 인증·쿠키 없는 HTTP GET과 비로그인 브라우저로 각각 확인한다. HTTP 200, 로그인 이동 없음, 올바른 회차, 한글·가격·숫자·날짜 포함 KST·원문 출처·보관함이 맞아야 한다. 검사 도구 부재 또는 게시/검증 실패이면 발송하지 않는다. 관찰하지 못한 성공을 만들지 않는다.
9. 카카오 대화 읽기는 요구하지 않는다. dispatch/<회차 ID>.json이 이미 attempted/sent/실패/불명확이면 재전송하지 않는다. 보내기 직전 최소 비민감 attempted 상태, 실제 KST/UTC 시각, URL, 배포한 커밋, 각 검증 결과를 원격에 새로 저장한다. 일반 fast-forward push 또는 실제 지원되는 API 조건부 생성으로 최초 하나만 생성되게 한다. 원격 재읽기로 성공을 확인하고 충돌·저장 실패·불명확이면 발송하지 않는다. 기존 attempted를 새 시도로 덮어쓰지 않는다.
10. 모든 조건과 실제 도구 권한이 충족될 때 연결된 PlayMCP 나챗방 도구로 요약과 정확한 회차 URL을 합쳐 200자 이하로 한 번만 보낸다. 시험 발송은 하지 않는다. 응답 실패/불명확에도 재시도하지 않는다. 최소 비민감 전송 상태만 갱신하며 갱신 실패는 재발송 이유가 아니다. 메시지 응답의 개인정보를 공개 저장소에 올리지 않는다.
11. 결과에 달력/거래일 판단과 출처, 예정/실제 시각, 클라우드 환경, Git 커밋, 배포 상태, 정확한 URL, HTTP/브라우저 각각의 관찰, attempted 저장 상태, 실제 카카오 도구 응답 상태를 사실대로 남긴다. 이전 계정이나 로컬의 다른 예약을 수정하지 않는다.
